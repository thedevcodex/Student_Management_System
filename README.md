# Student_Management_System

Sometimes learning to code gets frustrating. 😅

Instead of just practicing individual Python concepts, I decided to challenge myself by building a **Complete Student Management System** from scratch.

While building it, I revised and practiced:

🔹 Python OOP concepts
🔹 Lists & Dictionaries
🔹 Adding multiple student records
🔹 Searching students by ID
🔹 Updating specific student details
🔹 Deleting student records
🔹 Counting total students
🔹 Loops and `for-else`
🔹 Functions and conditional logic

Honestly, I got frustrated multiple times while building it. But that's exactly where the real learning happened.

I realized that **understanding a concept and using it to build a complete project are two different things.**

So instead of giving up, I decided to revise by building.

One project.
Many concepts.
A lot of debugging.
And a lot of learning. 

**Getting frustrated is part of the process. Keep building. Keep learning. Keep progressing.**
